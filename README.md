# Hospital_CarPark

This was a university project which required me to make a car park system that allows the user to pick between:

park a car
viewing parked cars
viewing free spaces within the car park
remove a parked car 
exit

they were the menu options when the code was ran so the user would have to enter a number for example number 1 was to view parked cars then the user would type 1 into the python terminal then it would show the parked cars. There was a text file that was read in so that the user could view the parked cars 

then if the user wanted to change the text file to add a car or remove a car, code was added to allow this to happen sing the append function within python.

overall it was a fun project to code i used AI to help with an error I had with reading the text file in but apart from that AI wasnt used any other time
